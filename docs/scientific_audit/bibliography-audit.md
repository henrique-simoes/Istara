# Bibliography Audit

Spec: CF-SPEC-123 / CF-1581; CF-SPEC-124 / CF-1590

The audit prefers primary arXiv, W3C, DOI, ACM, publisher, or official project sources. Secondary summaries should not drive Istara claims.
