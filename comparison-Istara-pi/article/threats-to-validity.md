# Threats To Validity

- Different engine primitives may bias raw implementation comparisons.
- A single cloud provider does not prove cross-provider robustness.
- Small smoke tests prove connectivity, not quality.
- Feature inventory rows are documentation-derived and require runtime confirmation.
- Pi package setup mode may affect latency, reliability, and observability.
- Judges must not see uncapped private prompts or secret-bearing traces.

Mitigation: paired scenarios, shared tool facade, capped retention, deterministic validators,
and evidence-linked `TBD-evidence` markers.
