# Usability Test U02

Scenario: Invite a caregiver to review tasks
Prototype: CareNav vB
Participants: 7

| Task | Completion | Median Time | Notes |
| --- | ---: | ---: | --- |
| Locate blocked tasks | 65% | 98s | Users scanned visit dates before task status |
| Identify missing evidence | 54% | 131s | Source trail label was missed by 4 participants |
| Send caregiver-safe update | 47% | 159s | Permission wording caused hesitation |

## Observed friction
- staff duplicate reminders in SMS, portal messages, and sticky notes.
- staff do not trust automation when no source trail is shown.
- Users expected a plain-language readiness reason next to the status.

## Moderator recommendations
- surface the source and freshness of each task.
- Test permission copy with caregivers before expanding the flow.
