# Usability Test U06

Scenario: Explain appointment readiness to a nurse
Prototype: CareNav vB
Participants: 8

| Task | Completion | Median Time | Notes |
| --- | ---: | ---: | --- |
| Locate blocked tasks | 58% | 130s | Users scanned visit dates before task status |
| Identify missing evidence | 47% | 175s | Source trail label was missed by 4 participants |
| Send caregiver-safe update | 40% | 195s | Permission wording caused hesitation |

## Observed friction
- Spanish and Portuguese copy is inconsistent across reminders.
- caregivers receive partial information and then call the clinic.
- Users expected a plain-language readiness reason next to the status.

## Moderator recommendations
- add confidence labels when evidence is incomplete.
- Test permission copy with caregivers before expanding the flow.
